# Go 习题生成器

当用户调用此 skill 时，为 D:\StartingGo 项目下的 Go 学习文件生成配套习题。

## 执行步骤

### 1. 扫描对比
- 扫描所有子文件夹中的 `.go` 源文件（跳过 `习题集.go`、`go.mod`、`go.sum`、`_习题.go` 等）
- 按文件夹分组：`Go_study_foundation/`、`Go_study_function/`、`Go_study_struct/` 等
- 对每个文件夹：
  - 如果 **没有** `习题集.go` → 新建，覆盖该文件夹所有源文件
  - 如果 **已有** `习题集.go` → 读取它，列出已存在的章节（通过 "对应：xxx.go" 匹配），只为 **新增的源文件** 生成新章节

### 2. 增量追加规则（习题集已存在时）
- 保留已有章节和答案，不做任何修改
- 新章节插入位置：习题区末尾（答案区开始之前）、答案区末尾（`*/` 闭合之前）
- 章节编号接着已有编号顺延（如已有 11 章，新章从 12 开始）
- 追加完后告知用户：哪些章是旧的、哪些是新增的

### 3. 全新生成规则（习题集不存在时）
每个文件夹生成一个 `习题集.go`，结构如下：

```
/*
╔══════════════════════════════════════════╗
║            Go xxx 习题集                  ║
║   对应文件：xxx.go ~ xxx.go               ║
╚══════════════════════════════════════════╝
*/

/*
╔═══ 第 N 章：知识点名称 ═══╗
║  对应：原始文件名.go         ║
╚═════════════════════════════╝

【习题 N.1】题目...
【习题 N.2】题目...
*/

// ... 所有章节 ...

/*
╔══════════════════════════════════════════╗
║           ✨✨ 答 案 区 域 ✨✨           ║
╚══════════════════════════════════════════╝

═══════════════════════════════════════════
  第 N 章 答案
═══════════════════════════════════════════

【习题 N.1 答案】
答案代码和解释...
*/
```

### 4. 题目要求
- 每题标注 `【习题 N.M】`，答案对应 `【习题 N.M 答案】`
- 题型混搭：概念填空、读代码写输出、找错纠错、手写编程、对比分析
- 覆盖该知识点文件中的核心概念
- 难度由浅入深

### 5. ⚠️ 关键规则
- **答案区用一个大的 `/* */` 包裹所有内容**
- **答案代码中的注释必须用 `//`，绝对禁止 `/* */`**（会导致外层注释提前关闭）
- **只生成一个文件/文件夹**，不要创建零散文件
- **不动原始学习文件和 Whm's Wonder Lab**
- **已有章节绝不修改，只追加新章节**

### 6. 完成后
- 告知用户本次新增了几个章节、约多少道题
- 列出新增的章节目录（不列旧章节）
